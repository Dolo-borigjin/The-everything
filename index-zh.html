五个任务族 = 五种失败模式

每族对应「自动发现有效理论」的一种典型翻车方式；防刷分机制公开写明，欢迎攻擂。

Known-Recovery

已知定律能否恢复——但评分扣到系数级。离散格式带来的系统偏差（如 FD 拉拽前锋滞后）会被如实扣分，「形状像」不算分。

Cross-Resolution

同一宏观律必须在多种网格下恢复出同一系数。过拟合某一分辨率的「定律」在这里直接现形。

Long-Horizon

闭合模型在 100× 训练视界上漂移审计。只在短程拟合得好、长程发散的系统拿不到分——标定是硬门槛。

Discovery

无教科书答案：系统必须输出带误差界的宏观方程与 regime 边界（含 theory_gap 诚实上报）。这是外部提交的最终仲裁族。

Extrapolation

校准域之外对拍。插值系统域内满分、域外崩溃；真定律携带适用范围继续成立。这是「定律 vs 插值」的分水岭题。

Chaos-Audit（混沌审计）

混沌区制下 Lyapunov 指数、吸引子距离等指标化进验收门——混沌约束不满足，卡不得进入 decision 级。

运行与复现

复现公开榜单（全绿）是任何外部提交的前置条件。逐题比对 |实测 − 榜单| ≤ 0.02，不一致非零退出。

# 复现仲裁（约 3–5 分钟，确定性管线）
cd arm
pip install -e .            # 或 pip install numpy scipy pytest
python -m scalebench.reproduce                          # 全量复现 + 榜单比对
python -m scalebench.reproduce --only nis_prune_consistency   # 单题
python -m scalebench.reproduce --report out.json              # 另存比对报告

外部提交与仲裁

  1. 前置：复现公开榜单（reproduce 全绿）——复现不了榜单就没有提交资格；
  2. 提交物：ETC 卡（误差界带校准记录）+ 考题输出 + 复现日志；
  3. 误差界核验：宣称覆盖率与实测不符（二项 z 检验，SPEC-002）→ 降级；
  4. 最终仲裁：Discovery 族——对无教科书答案的系统输出，由 held-out 实验数据仲裁。

诚实边界

未满分的题是物理难度的如实记录——而曾经的测量伪影也被同样诚实地修复： 把 known_recovery 压在 0.826 的 FD 拉拽前锋滞后，归因结果是 pulled front 的 代数暂态（不是离散误差），用 Ebert–van Saarloos 渐近估计量修正，其对数系数 带物理签名 b=−1.5√(D/r)——系数误差 0.290 → 0.004，得分 0.826 → 0.998， 事件全程入测试档案。分数的下限是物理本身的难度，上限由测量严谨度决定。 榜单全部数字来自仓库内模拟器（可复现、带解析参考），不依赖外部数据。
