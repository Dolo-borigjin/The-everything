Five task families = five failure modes

Each family maps to one canonical failure of learned effective theories; the anti-gaming mechanism of every task is public. Challenge them.

Known-Recovery

Can a known law be recovered — scored down to the prefactor. Systematic discretization bias was charged as measured; the FD pulled-front lag was then fixed by physics-aware asymptotic estimation (Ebert–van Saarloos), prefactor error 0.290 → 0.004. Artifacts get fixed, physics stays.

Cross-Resolution

The same law must come out of multiple grids with the same prefactor. Grid-overfit "laws" are exposed here.

Long-Horizon

Closures are audited for drift over 100× the training horizon. Systems that only fit short horizons fail — calibration is a hard gate.

Discovery

No textbook answer: the system must emit a macroscopic equation with error bars and regime boundaries (theory_gap reported honestly). This is the final arbitration family for external submissions.

Extrapolation

Evaluated outside the calibration domain. Interpolators score perfectly inside and collapse outside; true laws carry their validity range. The law-vs-interpolation watershed.

Chaos-Audit

Lyapunov exponents and attractor distances enter the acceptance gate — chaos constraints must be measured, not assumed, before a card is decision-eligible.

Run & reproduce

Full reproduction of the public leaderboard (all green) is a precondition for any external submission. Per-task comparison |measured − leaderboard| ≤ 0.02, nonzero exit on mismatch.

# Reproduction arbitration (~3–5 min, deterministic pipeline)
cd arm
pip install -e .            # or pip install numpy scipy pytest
python -m scalebench.reproduce                          # full rerun + leaderboard check
python -m scalebench.reproduce --only nis_prune_consistency   # single task
python -m scalebench.reproduce --report out.json              # save comparison report

External submissions & arbitration

  1. Precondition: reproduce the public leaderboard (all green) — no reproduction, no submission;
  2. Submission: ETC card (error bars with calibration record) + task outputs + reproduction log;
  3. Error-bar check: claimed coverage vs measured (binomial z-test, SPEC-002) → downgrade on mismatch;
  4. Final arbitration: the Discovery family — system outputs for questions with no textbook answer are judged by held-out experimental data.

Honest boundaries

What remains sub-unity is physical difficulty, honestly recorded — and what was a measurement artifact got fixed, honestly too: the FD pulled-front lag that held known_recovery at 0.826 turned out to be an algebraic transient of pulled fronts (not discretization), and was corrected by an Ebert–van Saarloos asymptotic estimator whose log-coefficient carries the physical signature b=−1.5√(D/r) — prefactor error 0.290 → 0.004, score 0.826 → 0.9975, with the episode documented in tests. The floor of a ScaleBench score is the difficulty of the physics; the ceiling is set by measurement rigor. All leaderboard numbers come from in-repo simulators (reproducible, with analytic references) and depend on no external data.
